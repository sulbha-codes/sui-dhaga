# Sui Dhaga — Custom Tailoring & Matching Centre

A responsive business website for **Sui Dhaga**, a custom tailoring and matching centre located in Balewadi, Pune.

The website introduces the shop’s services, showcases its fabric and tailoring work, and helps customers connect with the business through WhatsApp or visit the shop.

## Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
- **Business Landing Page** — Introduces Sui Dhaga and its tailoring services.
- **Services Section** — Highlights fabrics and matching, custom tailoring, and alterations.
- **Image Gallery** — Showcases shop photos and fabric collections through a carousel.
- **WhatsApp Enquiry** — Allows customers to contact the shop directly.
- **Mobile Navigation** — Includes a responsive navigation menu.
- **Shop Information** — Displays the business address, opening hours, and Google Maps directions.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd sui-dhaga
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
